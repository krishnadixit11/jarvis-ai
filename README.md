# 🤖 JARVIS AI Assistant

JARVIS AI Assistant is a modern, modular, voice-controlled desktop assistant built with Python. Inspired by Iron Man's JARVIS, this project is designed to automate everyday computer tasks, provide intelligent AI-powered conversations, and create a seamless hands-free desktop experience. The project follows a clean, scalable architecture so that new features and integrations can be added easily in the future.

JARVIS can listen to voice commands, understand natural language, and respond with realistic speech. It can open websites, search Google and YouTube, launch Windows applications, manage files and folders, answer questions using advanced AI models, and perform various desktop automation tasks. The assistant is built with a modular structure, making it easy to maintain, extend, and integrate with new technologies.

## ✨ Key Features

* 🎙️ Voice Recognition using SpeechRecognition and Whisper AI
* 🗣️ Natural Text-to-Speech Responses
* 🧠 AI-Powered Conversations with Gemini/OpenAI Integration
* 🌐 Open Websites with Voice Commands
* 🔍 Google Search Automation
* ▶️ YouTube Search Automation
* 💻 Launch Windows Applications (Notepad, Calculator, Paint, CMD, File Explorer, etc.)
* 📁 File & Folder Management
* 📅 Date & Time Information
* 👋 Smart Greetings and Interactive Responses
* ⚡ Fast Command Processing
* 🧩 Modular Project Architecture
* 📜 Detailed Logging System
* ⚙️ Easy Configuration using Environment Variables (.env)
* 🚀 Easily Extendable with New Features

## 📂 Project Structure

The project is organized into separate modules for AI, automation, speech processing, command routing, logging, GUI, plugins, and database management. This modular design allows developers to add new capabilities without affecting the existing system.
